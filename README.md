# Profe de Voz

App para aprender cualquier tema por etapas, hablando con un profe hecho con Claude.

- Abrila en Chrome (celular o compu) e instalala con "Agregar a pantalla de inicio" / "Instalar app".
- La primera vez pegá tu clave de API de Anthropic en Ajustes. Se guarda solo en tu equipo.

## Sonidos

Los sonidos grabados de la carpeta `sfx/` son de dominio público (licencia CC0 1.0), tomados de
[EternityForest/free-sfx](https://github.com/EternityForest/free-sfx) (que reúne sonidos CC0 de Freesound, OpenGameArt y otros).
Se recortaron y se pasaron a .ogg livianos. El resto de los sonidos se generan en el momento con Web Audio.
